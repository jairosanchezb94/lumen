# Inicio

Launcher estilo tvOS para televisores Samsung con Tizen, como módulo de [TizenBrew](https://github.com/reisxd/TizenBrew).

- Lee las apps instaladas en la TV (`tizen.application.getAppsInfo`) y las abre con OK.
- Dock de favoritos arriba y todas las apps debajo.
- Mantén OK (o pulsa el botón amarillo) para fijar o quitar una app de favoritos. Se guardan en la TV.
- Logos de marca con [Simple Icons](https://simpleicons.org); las apps sin logo usan su icono o su nombre.

## Instalar

En TizenBrew: Module Manager > Add GitHub Module > `jairosanchezb94/tv-launcher`, y abre **Inicio**.

## Probar en el ordenador

Abre `app/index.html` en el navegador. Sin la API de Tizen muestra una lista de apps de ejemplo y se maneja con las flechas y Enter.
